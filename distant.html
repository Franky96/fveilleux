Connexion à distance

Bureau à distance du cégep

📚 Manuels de maintenance

Accès au poste « MANUELS » du laboratoire du Cégep Édouard-Montpetit, par la passerelle de Bureau à distance du cégep. Connecte-toi avec ton compte du cégep.

Passerelle : rds.cegepmontpetit.caCollection : MANUELS
🖥️ Ouvrir dans le navigateurClient web du cégep : connecte-toi, puis clique sur « MANUELS ». S'ouvre dans un nouvel onglet. ⬇️ Ouvrir avec l'application Bureau à distanceTélécharge le fichier de connexion (.rdp), puis ouvre-le : il lance l'application.

Si le navigateur ne fonctionne pas

  • Windows : ouvre le fichier .rdp téléchargé, la Connexion Bureau à distance est déjà installée.
  • Mac, iPad, iPhone : installe Windows App (gratuite), puis ouvre le fichier .rdp avec elle.
  • Android : installe Windows App depuis le Play Store, puis ouvre le fichier .rdp.
  • Hors du réseau du cégep, la passerelle peut exiger une double authentification du cégep ou refuser certaines connexions : c'est le cégep qui gère cet accès.
