# Simulateur PT6A-21

Turbopropulseur Pratt & Whitney Canada PT6A-21, reconstitué en 3D (three.js 0.147) d'après les manuels P&WC (AMM 3013242,
OM 3013243, IPC 3013244), avec une simulation de fonctionnement. Page `pt6a21.html`, permission `pt6a21` (groupe `moteurs`).

## Fichiers

| Fichier | Contenu |
|---|---|
| `pt6a21.html` | Page, modèle complet et simulation (voir les sections ci-dessous) |
| `pt6a21-rgb.js` | Réducteur d'hélice, chapitre 72-10 : `construireRGB(THREE)` |
| `pt6a21-turbines.js` | Turbines et échappement, 72-50 : `construireTurbines(THREE)` |
| `pt6a21-gg.js` | Générateur de gaz, 72-30 : carter, compresseur, chambre de combustion, collecteur carburant 73-10, diviseur de débit, palier n° 1… (`construireGG(THREE)`) |
| `pt6a21-eclate.js` | Vue éclatée sur l'axe et démontage pas à pas, communs aux modules (`Eclate(THREE)`) |

Sections de `pt6a21.html`, dans l'ordre :
1. MATÉRIAUX ;
2. MODULE AVANT ;
3. TURBINES (montage du module) ;
4. GÉNÉRATEUR DE GAZ (montage, flamme) ;
5. boîtier d'accessoires ;
6. PARTICULES (trajet du gaz) ;
7. CIRCUIT D'HUILE ;
8. SIMULATION (`st`, `step(dt)`) ;
9. JOURNAL ET SÉQUENCES AUTO ;
10. INTERFACE ;
11. INSTRUMENTS ;
12. AUDIO.

**Empreintes** : les modules sont chargés avec `?v=<8 premiers caractères du sha256>`. Après toute modification d'un module :
`for m in eclate rgb turbines gg; do h=$(sha256sum pt6a21-$m.js | cut -c1-8); sed -i -E "s#pt6a21-$m\.js(\?v=[0-9a-f]+)?\"#pt6a21-$m.js?v=$h\"#" pt6a21.html; done`

## Conventions des modules

- **Unités** :
  - pouces ;
  - `z` = distance vers l'arrière depuis la face de la bride d'hélice ;
  - `r` = rayon ;
  - `h` = position horaire vue de l'arrière (12 h en haut, sens horaire).
- **Échelle** : 1 unité three.js = 10 po (`S = 0.1`). La page met chaque module à l'échelle ½ et place son point `Z0` sur l'axe.
- **Aides de placement** :
  - `clockPhi(h)` = h/12·2π + π/2 (angle) ;
  - `P(r, z, h)` et `Pf(r, z, φ)` donnent des points ;
  - `radM(r, z, φ)` donne un repère local avec X tangentiel (sens horaire vu de l'arrière), Y = rayon vers l'extérieur et Z axial vers l'arrière.
    Avec `radM(0, z, φ)`, on construit une pièce en coordonnées locales où Y vaut directement le rayon.
- **Formes de révolution** : `lathe()`, `revolve()`, `latheUV()`, `ringPts()`, `sheet()` (tôle épaissie).
  - Les profils sont remis dans le sens qui tourne les faces vers l'extérieur de la matière (`aire()`, `profilLathe()`).
  - `geometry.userData.profil` sert aux faces de coupe planes.
- **Pièces** :
  - `part(id, { kind })` crée le groupe ; `M(id, {...})` crée un matériau rattaché à la pièce.
  - `kind: 'case'` = pièce fixe coupée en mode coupe ; les autres pièces ne sont coupées qu'avec « Toutes les pièces ».
  - `inst()` = InstancedMesh ; `boltMat(id)` = boulons.
- **Fiches** : `INFO[id] = { g: famille, n: nom, ref: références des manuels, d: description, k: [[clé, valeur]…] }`.
  Les cotes estimées sont dites « estimées ». Les pièces du modèle complet ont leurs fiches dans `pt6a21.html`.
- **Démontage** : `STEPS = [{ t, r: référence OM, m: [[[ids], { dz, dr, up }]], d }]`. `ORDRE` et `ANCRE` règlent la vue éclatée.
- **Rotors** : `update(angleNg)` / `TB.update(angNg, angNf)` / `RGB.update(angNf)`.
- **Vue en coupe** :
  - les faces arrière sont peintes en plein (`coupePleine()` dans la page) ;
  - des faces planes ferment les pièces de révolution (`majCaps()` à chaque image) ;
  - `userData.creux` marque une tôle sans épaisseur, qu'on laisse creuse.

## Simulation (pt6a21.html)

- **État** `st` : `Ng`, `Np`, `itt`, `wf` (débit carburant, lb/h), `lit` (allumé), `trq`, `oilP`, `oilT`, `beta`…
- **Commandes** `inp` : carburant (`master`), manette de condition `fcl` (coupé, ralenti sol, ralenti vol), manette de puissance `pcl`, hélice, démarreur, allumage, conditions au sol (OAT, altitude).
- Démarrage et arrêt automatiques, alarmes (ITT, couple, Ng…), journal, instruments, son.
- **Visuels liés à la simulation** :
  - la flamme (`flameMat`) ;
  - les jets des injecteurs (`GG.carburant(prim, sec)` : primaires dès que le carburant arrive, secondaires de 28 à 40 % de Ng) ;
  - les particules du flux d'air ;
  - le circuit d'huile (modes masqué, visible, isolé, écoulement).
- **Modes d'affichage** : Extérieur, Coupe ¼, Moitié, Rayons X. On peut isoler une section (`#piece`) et suivre les étapes de démontage pas à pas.

## Travaux faits (octobre 2026)

- Coupe pleine : faces de coupe planes, disques pleins, sans hachures (demande de l'utilisateur).
- Collecteur carburant et adaptateurs d'injecteurs refaits d'après l'AMM, l'IPC et l'OM 73-10-05 :
  - 10 adaptateurs primaires et 4 secondaires aux n° 6, 7, 8 (entrée) et 14 ; numéros marqués sur le carter, n° 1 à 12 h, sens horaire vu de l'arrière ; indice du modèle = n° + 2 ;
  - gaines, injecteurs, tubes de transfert droits, plaques de verrouillage ;
  - jets tangentiels de 42°.
- Diviseur de débit et clapet de vidange (pré-SB1406, AMM 73-10-04) sous l'adaptateur d'entrée.

## Manuels

- Jamais dans le dépôt (public). L'utilisateur les téléverse dans la conversation, par exemple `PT6A-21_73-10.zip` avec AMM, IPC et OM 73-10.
- Les extraire dans le dossier de travail de la session, puis :
  - texte avec `pdftotext` ;
  - figures avec `pdftoppm -f N -l N -r 110 -png` ;
  - recherche d'une page : `pdftotext -f p -l p … | grep "C52092A"`.
- Une nouvelle conversation ne les a plus : les redemander.
- Sur le serveur, ils sont hors du site web et servis par `api/manuel.php?m=PT6A-21&doc=AMM&f=72-30.pdf`.

## Tester

- Voir `docs/DEMARRAGE.md` (serveur local, Playwright). Pour la 3D : `args: ['--use-gl=swiftshader', '--enable-unsafe-swiftshader']`, permission `pt6a21`, et `localStorage.setItem('pt6a.menus','0')` pour fermer les menus.
- Inspection : `window.__pt6 = { RGB, TB, GG, pickables, secOf, setIso, eng, scene, camera, controls }`.
  - Point du générateur de gaz en coordonnées monde : `GG.root.localToWorld(GG.P(r, z, h))`.
  - Placer la caméra : `camera.position.set(...)` et `controls.target.set(...)`, puis `controls.update()`.
  - Le faire deux fois de suite : le premier réglage peut être écrasé par le cadrage animé d'une section.
- Isoler une section : `document.getElementById('piece').value = 'gg'`, puis lui envoyer un événement `change`.
- Changer de mode : `document.getElementById('m-cut' | 'm-xray' | 'm-half' | 'm-ext').click()`. Les captures en coupe sont lentes sous swiftshader.
